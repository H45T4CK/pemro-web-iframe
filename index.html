• Apa gunanya IFRAME?
    Jawaban:
    IFRAME (Inline Frame) berguna untuk menyematkan (embed) dokumen HTML lain, halaman web eksternal, maupun media interaktif (seperti video atau peta) langsung di dalam halaman web yang sedang aktif tanpa harus memuat ulang seluruh halaman.

  • Apa bedanya FRAME dan IFRAME?
    Jawaban:
    • FRAME (<frameset>): Digunakan untuk membagi seluruh layar browser menjadi beberapa bagian terpisah dan kedudukannya menggantikan tag <body>.
    • IFRAME (<iframe>): Merupakan inline frame yang ditempatkan di dalam tag <body> bersanding dengan elemen HTML lain (seperti teks atau gambar), serta ukurannya dapat diatur secara bebas.

  • Tuliskan bentuk umum perintah IFRAME secara lengkap?
    Jawaban:
    <iframe src="URL" name="nama_frame" width="lebar" height="tinggi" frameborder="1|0" scrolling="yes|no|auto">
    <p>Teks ini tampil jika browser tidak mendukung IFRAME.</p>
</iframe>
